# Agent logos

这些图标用于在 AgentHub 中识别对应集成，商标归各自所有者。`AgentLogo`
会优先加载 SVG、失败后加载 PNG；WorkBuddy 和 ZCode 暂无可验证的纯矢量来源，因此直接使用 PNG。SVG 于 2026-08-31 获取，并已检查为没有脚本、外链或嵌入远程内容的静态文件。
Pi 的 SVG 移除了随系统主题改成白色的规则，以保证它在头像的浅色底上始终可见。
