# Chat 体验标杆

用户标准：Chat 对标 Claude Code、Cursor Chat、Codex app，要做到好用易用。本页写**目标**和**当前事实**。布局与控件仍以 [页面模式 · Chat](page-patterns.md#8-chat) 为准；各家接线以 [Chat 与 Agent](../concepts/chat-and-agents.md) 和 [STATUS](../STATUS.md) 为准。

好用指手感：发出去能看着它干活；生成时还能补充、排队或停止；批准写得清；模型、思考、图片、技能就在输入区附近；出错有下一步且草稿还在；关上再开还是这场对话；空会话就可以打字；常用动作能用键盘。

| 面 | 目标 | 当前事实 |
| --- | --- | --- |
| 流式 | 正文随生成出现。过程是「正在读取 / 正在修改 / 正在执行」，细节可展开。 | 新空 Codex / Grok / Kiro 持续聊天：活动会话约 80ms 读快照，正文用同一次读取的完整 currentMessage，不用字符串猜增量，也不把整段回复拆开假装逐字打出。首字前显示「正在想」，正文出现后「正在写」并带光标。过程摘要和工具行是「正在读取 / 正在修改 / 正在执行」（完成则「已读取 / 已修改 / 已执行」），路径或命令跟在后面；工具名、状态和 JSON 进折叠的「细节」。思考带计时。进行中展开、结束后折叠。Claude 与旧会话仍是一次性发送。 |
| 用量 | 对话过程里能看见当前轮和累计，数字来自对方。没有数据不画假进度条。 | Codex 持续聊天：`thread/tokenUsage/updated` 的当前轮 last 与累计 total；有窗口时写 n / 窗口。Grok 只有当前轮（`turn_completed.usage`），没有会话累计字段。Kiro 无 token 累计数据源。 |
| 输入区 Enter / 排队 / 停止 | `Enter` 发送，`Shift+Enter` 换行。生成中能补充（不打断当前动作）或排队到下一轮，两种动作分得清。停止先「正在停止」，确认后再「已停止」。中文输入法组字时 `Enter` 不发送。 | 输入区下方写当前快捷键。`Enter` 发送，组字时不发。生成中 Codex 为补充，Grok / Kiro 为排队；空草稿不画假发送。排队条显示条数和预览，可整段取消。停止带「停止」二字，点了之后是「正在停止」。发送后焦点留在输入框。`Esc` 仍可停。 |
| 审批 | 卡片是「允许」「拒绝」；「一直允许」写清管到这场对话还是本轮。改文件能看见路径和将要改的内容。 | 卡片先写种类再写标题；允许 / 拒绝；带了该选项才出一直允许，并写「仅当前这次进程，不保存」。点了之后三家都在当前进程里记住：Codex 通常本轮；Grok / Kiro 同一条 ACP 进程可跨轮。没有该选项不画按钮。文件卡标题「修改文件」并用等宽字显示路径。Kiro「完全访问权限」是启动时的会话设置。 |
| 模型与思考 | 输入区旁显示当前模型和思考强度；选项来自这份登录真实可用的列表；换模型后强度跟着变；生成中不改正在跑的一轮。 | Codex / Grok 可持续聊天里可换模型和思考强度，拒绝后保留原值。菜单用可读名（如 GPT 5.3 Codex Spark），当前项打勾。思考强度旁有短说明（可能更慢）。Kiro 开始后要换需新建对话。`Ctrl+Shift+I`（macOS 也认 `Cmd+Shift+I`）打开模型菜单。 |
| 附件 | 发送前能看见已加的图片或文件，可移除。支持选图、粘贴、拖入；工作目录里的文件能点名带上。 | 持续聊天已接本地图片（选图 / 粘贴 / 拖入，最多 8 张、单张 10MB）。普通文件和 `@` 提文件尚未接入。 |
| 用于本次技能 | 当前 Agent 可调用的技能能选进这一条，选中后看得到。对方做不到时不画可点的假入口。 | 新空 Codex 会话可把有稳定路径的技能标成用于本次。Grok 无此能力，界面不画假按钮。`/` 打开的是本地操作和示例草稿。 |
| 错误文案 | 失败、停止、超时用一句话说明，并给一个下一步（换模型、去连接、填回草稿）。草稿保留。 | 有失败 / 中断 / 停止 / 超时横幅，可填回草稿和重试。常见登录失效、用量、模型下架、思考强度不支持已译成人话。过程里的坏行写成「有一行输出没法展示」。 |
| 续聊 | 点开历史立刻看到上次正文。生成中切走再回来，任务还在。关窗口再开，同一场对话能接着说。 | 切会话不取消生成。Codex 关窗续聊 Linux 真窗已验、macOS 重开有效，Windows 未宣称。Grok 旧会话可「用新方式继续」。Kiro 同一进程内续聊；进程退出后留历史并提示新建。 |
| 空状态 | 空会话焦点在输入区。示例只填草稿、不代发。缺目录或登录时一条提示加恢复，不占满中间。 | 空会话焦点在输入区。示例是输入区上方的一行芯片（只填草稿）。缺条件时一条提示加恢复，不占满中间。没有 Agent 时去 Agent 页。 |
| 键盘 | `Enter` 发送，`Shift+Enter` 换行，`Esc` 停止，`/` 搜操作。能新建对话、打开模型菜单，并能看到当前快捷键。 | 输入区下有快捷键一行。`Enter` / `Shift+Enter` / 组字时不发送 / `Esc` 停止 / `/` 本地菜单已有。`Ctrl+K`（macOS `Cmd+K`）聚焦历史搜索。`Ctrl+Shift+I`（macOS 也认 `Cmd+Shift+I`）打开模型菜单。尚无新建对话快捷键、也无快捷键一览。 |

前沿对照日期 2026-09-09，依据各家公开文档： [Claude Code 桌面](https://code.claude.com/docs/en/desktop)、[Cursor Agent](https://cursor.com/docs/agent/overview)、[Codex app](https://developers.openai.com/codex/app)。各家能力不同；本页不承诺每家生成相同答案，也不把未接线的 Claude 持续聊天写成已完成。

共用界面和各家对接计划仍见 [Chat 统一体验](../proposals/chat-unified-experience.md)。
