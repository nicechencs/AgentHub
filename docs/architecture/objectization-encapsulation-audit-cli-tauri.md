# 对象化与封装审查：CLI、Tauri 与工具链

本分册记录 CLI、Tauri、根目录脚本、发布配置和工作流的逐文件审查结果。问题编号与总览文档一致；旧问题见[对象化与封装审查](objectization-encapsulation-audit.md)。

## 覆盖范围

本分区逐项检查了 63 个路径，其中包括 CLI 23 个、根目录与脚本 19 个、Tauri 配置与源码 28 个、Tauri 测试、生成 schema、图标资源和 GitHub Workflows。可执行源码、测试、脚本和配置均检查对象职责；生成文件和二进制只确认其不承载业务对象行为。

CLI 整体是薄壳：参数解析、输出和退出码集中，业务操作委托给 Core Service；根脚本的读取、归一化、校验和写入职责也基本集中。

## 新增问题

### O-62｜Tauri 账号命令直接读取认证对象

- **位置：** `src-tauri/src/commands/account.rs:224-245`
- **状态：已处理**
- **问题：** 命令层直接调用 `hub.registry.get(...).read_auth()`，并自行补充 `also_present` 状态，绕过账户/认证服务的统一对象。
- **建议：** 由账户或认证服务提供“当前认证状态及投影状态”查询，Tauri 只做参数转换和线程调度。
- **影响：** 认证状态规则可能与账户服务分叉，CLI、桌面端和其他入口会产生不同结果。

### O-63｜Tauri 设置读取、默认值和同步职责散落

- **位置：** `src-tauri/src/commands/settings.rs:14-104`、`src-tauri/src/state.rs:160-168`、`src-tauri/src/tray.rs:352-360`、`src-tauri/src/commands/settings/pick_directory.rs:44-55`
- **状态：部分处理**
- **问题：** 设置读取、默认值、运行时同步和语言读取由多个入口分别维护。
- **建议：** 由 Settings/AppPreferences 对象提供强类型读取、更新和变更通知；命令、托盘和目录选择只消费该对象。
- **影响：** 设置 key、默认值和同步时机需要多处共同维护。

### O-64｜Adapter 错误分类在 Tauri 层与前端重复维护

- **位置：** `src-tauri/src/commands/mod.rs:78-110`
- **问题：** 错误码和 retryable 规则硬编码在 Tauri 层，并要求与前端另处同步。
- **建议：** 提供共享错误分类契约，或由单一注册表生成两端映射。
- **影响：** 跨层错误行为容易漂移。

### O-65｜卸载命令自行承担备份策略

- **位置：** `src-tauri/src/commands/install.rs:197-218`
- **状态：已处理**
- **问题：** 命令层决定卸载前是否备份，并同时调用备份快照和卸载用例。
- **建议：** 将卸载、备份和失败补偿封装进生命周期/安装服务，Tauri 只传入卸载意图。
- **影响：** CLI、桌面端和后续入口可能采用不同的卸载前置策略。

### O-66｜Adapter bridge controller 承担过多状态和事务职责

- **位置：** `src-tauri/src/adapter_bridge_controller.rs`
- **问题：** 单文件同时负责桥接运行时、端口选择、配置投影、Saga、回滚、恢复、状态索引和错误映射。
- **建议：** 拆为桥接生命周期、投影事务、恢复/补偿和成员解析对象；Controller 只保留组合与调度。
- **影响：** 修改和测试影响面大，职责边界不清，容易与 Core Bridge Service 重复编排。

### O-67｜托盘模块混合 UI、生命周期和桥接批处理

- **位置：** `src-tauri/src/tray.rs`
- **问题：** 同时负责托盘菜单、国际化、退出确认、桥接批处理、窗口显示和重启协调。
- **建议：** 将托盘 UI 控制器与退出/重启协调对象分开；桥接批处理走已有生命周期用例。
- **影响：** UI 事件与应用生命周期状态耦合，状态规则散落。

## 其余文件结论

- CLI 命令、CLI 测试、发布脚本、价格更新脚本、文档检查脚本、Tauri 大多数命令、退出协调器、窗口策略、技能监听和工作流文件均已逐文件检查，未发现新的对象化问题。
- `src-tauri/gen/schemas/**`、图标和 `app-icon.svg` 已检查，但属于生成/资源文件，不承载可拆分的业务对象行为。
- 版本在多个发布文件中重复保存，但已有脚本负责校验；按总审查口径，这属于发布机制，不作为对象化问题。

## 调整方向

优先把 Tauri 命令收窄为“参数转换 + 调度 + DTO 映射”，把认证读取、卸载策略、设置解析和桥接事务分别归还给对应 Core 对象；托盘只保留界面事件和应用生命周期调用。
